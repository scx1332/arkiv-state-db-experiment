# Repository working agreement

This repository is our playground for building a database that works well for
Arkiv. Experiment here and revise the local design when it improves that goal.

- Work on `main`. After completing and validating authorized changes, commit
  and push them to `origin/main` without asking for another confirmation.
- Keep this repository's implementation plans and design decisions here.
  Company specifications are references; this playground may deliberately
  depart from them when the user chooses a different direction.
- Other repositories belong to the company. Do not modify, commit, or push
  them without a separate explicit user instruction. In particular, do not
  change `arkiv-source-of-truth` as a side effect of work in this repository.
- Keep pushes scoped to this repository and preserve unrelated user work.
  Do not force-push or discard changes to make a push succeed.
